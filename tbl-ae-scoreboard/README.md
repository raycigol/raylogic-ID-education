# 2026 TBL Application Exercise — 純成績板

這是「教師單機」的成績輸入及投影版本，**不顯示病例、題目、選項或正解**，與原先的 Application Exercise 案例版分開。

- 共 13 組，四階段上限依序 10、25、35、30 分，總分 100。
- 每格直接輸入階段得分（允許 0.5 分間距），留空表示尚未輸入，0 表示實際得 0 分。
- 可修改組名；即時計算各組累計、平均、完成數及排行榜。
- 投影模式隱藏教師控制列；按「退出投影模式」恢復。
- 成績只保存在本機瀏覽器 localStorage；可匯出 CSV、匯出或還原 JSON。
- 若清除瀏覽器資料，可能遺失成績；每堂課建議備份。
- **不具備跨裝置同步**，GitHub Pages 僅提供靜態網頁。

操作方式：開啟 `index.html`，用 Chrome、Safari、Edge 皆可。可部署到 GitHub Pages 子資料夾。
