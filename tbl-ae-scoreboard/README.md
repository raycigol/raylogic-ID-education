## 課堂操作
1. 在各組、各階段下拉式選單選擇答案字母；旁邊即時顯示該題得分，累計及排行榜自動更新。
2. 未作答保持「未作答」空白，與 0 分有別；目前尚未完成時的排名是暫時排名。
3. 使用「投影模式」向全班展示**分數及名次**，不顯示輸入的答案字母；退出後教師可繼續操作。
4. 支援修改組別名稱、CSV（答案及各階段分數）匯出、JSON 備份與還原、清除紀錄。
5. 此版以新的 localStorage 儲存格式保存答案；原手動分數 V1 不會自動轉換為選項答案，但可保留既有組別名稱。

資料僅存在使用者的瀏覽器本機，清除資料可能遺失紀錄，建議每次課程備份。**沒有跨裝置同步功能**；部署在 GitHub Pages 仍是單機教師管理版。
