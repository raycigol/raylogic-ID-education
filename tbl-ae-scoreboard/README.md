## 課堂操作
1. 在各組、各階段下拉式選單選擇答案字母；旁邊即時顯示該題得分，累計及排行榜自動更新。
2. 未作答保持「未作答」空白，與 0 分有別；目前尚未完成時的排名是暫時排名。
3. 使用「投影模式」向全班展示**分數及名次**，不顯示輸入的答案字母；退出後教師可繼續操作。
4. 支援修改組別名稱、CSV（答案及各階段分數）匯出、JSON 備份與還原、清除紀錄。
5. 此版以新的 localStorage 儲存格式保存答案；原手動分數 V1 不會自動轉換為選項答案，但可保留既有組別名稱。

資料僅存在使用者的瀏覽器本機，清除資料可能遺失紀錄，建議每次課程備份。**沒有跨裝置同步功能**；部署在 GitHub Pages 仍是單機教師管理版。

## V3：鎖定後才公布分數
- 教師逐組選擇 A–E，未鎖定的階段**不顯示分數、也不計入累計與排名**。
- 每個 Stage 的 13 組答案填完後，按「鎖定並公布分數」；鎖定後無法修改該階段答案，分數才會顯示。
- 投影模式只顯示已鎖定階段分數及累計排名，不顯示答案字母。
- 下拉選單採固定寬度，額外得分文字使用固定高度，避免輸入後欄位偏移。
- 使用獨立 V3 本機存檔；從 V2 升級可匯入原答案（預設全部未鎖定），備份請使用 V3 JSON。


## V4：學生唯讀查分頁
- 教師先輸入各組 A–E，並於各 Stage 完成後按「鎖定並公布分數」。
- 按教師頁「產生學生查分連結」，複製並提供給學生；學生開啟 `student.html` 的分享網址即可看**已鎖定**階段的分數、累計及排名。
- 學生頁不顯示病例、題幹、選項文字、答案字母或正解。
- **這是唯讀快照，不是即時同步**；教師下一階段鎖定後，需要重新產生並傳送最新連結。
- 成績寫在分享網址的 `#` 片段中，連結持有人可讀取各組分數。避免在組名填入學號或姓名等敏感資料。
- 學生不能透過此頁修改教師成績；這不代表具備防竄改的伺服器驗證，正式成績以教師端為準。
