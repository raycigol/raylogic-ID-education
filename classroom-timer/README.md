# 課堂計時

獨立的 GitHub Pages 計時頁，供 iRAT／tRAT 投影。無登入、資料庫或外部套件，不讀寫課堂答案、成績及代表綁定。

- iRAT 15 分鐘與 tRAT 25 分鐘是可修改的快捷值，按下後仍需再按「開始計時」。
- AE 提供四階段共 55 分鐘的建議流程：Stage 1 討論／提交／回饋 6／1／5 分鐘；Stage 2 為 7／1／5；Stage 3 為 8／1／6；Stage 4 為 7／1／7。各階段總長為 12、13、15、15 分鐘。
- 選擇 AE 後從 Stage 1 小組討論開始，也可直接選階段或分段。每段到時停在零，不自動切換；按「下一段」只載入下一段時間，需再按「開始計時」。完整 12 段依序為討論、提交、回饋，最後一段不會循環回到開頭。
- 投影標題顯示 AE 階段及分段，適用全螢幕與現在時間模式。分段位置與計時狀態一併保存在目前分頁，重新整理可接續；切換未完成的分段需確認。自訂時間只更改目前分段，下個分段仍使用建議值，55 分鐘不包含暫停或額外延長。
- AE 計時不連接教師控制台，不會自動提交、鎖定、公布答案或修改成績；13 組提交與教學節奏仍由教師掌握。
- 可自訂分鐘／秒、暫停／繼續、重設，以及增加或減少一分鐘。變更尚未結束的階段或重設前會確認。
- 「現在時間」以裝置時鐘及台北時區顯示 24 小時制，切換顯示模式不會暫停倒數。
- 倒數以裝置的結束時間計算，避免背景分頁的更新頻率影響剩餘時間。進度保存在目前分頁的 sessionStorage；重新整理會依原結束時間接續，不同步其他裝置或分頁。更改裝置時鐘會影響計時。
- 最後一分鐘變色；到時停在 00:00，顯示「時間到」。提示音預設關閉，可自行開啟；播放受瀏覽器、自動播放限制、裝置音量與背景／休眠狀態影響，不保證分頁關閉後發聲。
- 全螢幕及專注投影可隱藏設定區。空白鍵開始／暫停，R 重設，F 切換全螢幕；在輸入框或按鈕操作時不觸發快捷鍵。
