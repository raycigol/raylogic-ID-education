# 學生離開組別

學生按「離開組別／重新加入」確認後，先由 `tbl_student_leave_session(session, expected_team_number)` 解除本人在目前課堂的代表綁定，成功才登出本機。網路或 RPC 失敗保留登入，方便重試。原組答案、得分、加入碼、其他組及其他課堂綁定皆不更動。

教師開啟「組別代表」分頁時，每 4 秒讀取目前課堂的代表清單；切換課堂後忽略先前課堂的延遲回應。

## 安裝

1. 在對應 Supabase 專案的 SQL Editor 貼上並執行完整的 `sql/student-leave.sql`。
2. 此 SQL 可重複執行，只建立／更新函式和既有 authenticated 角色的執行權限，安裝時不更動任何課堂資料。匿名學生只能解除自己的綁定；未登入或教師身份不能使用。
3. 函式安裝成功後再部署學生頁、教師頁與對應腳本。重新整理兩頁以取得新版本。
4. 舊版已登出的學生無法再用原本的匿名身份解除殘留綁定，這類既有紀錄仍須教師核對後解除一次。不要批次清空代表，也不需要重置課堂。

函式先鎖定組別邀請紀錄，再鎖定本人綁定，與加入及教師解除流程使用相同鎖定順序。預期組號不符則拒絕，已解除則回傳 0。

- `node tests/student-leave-db.cjs`（需 @electric-sql/pglite）：重複安裝、本人與課堂範圍、過期組號、重複離開、其他代表與正式課堂身份保留、答案／得分／代碼不變及角色權限。
- `node tests/representatives.cjs`：代表更新、取消、指定代表解除、課堂切換及舊請求防護；代表分頁可見時自動更新，隱藏時不輪詢。
