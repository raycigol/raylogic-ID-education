# 教師統一計時／學生同步倒數

教師在「課程控制 → 學生同步計時」選 Stage、用途（小組討論／提交答案）、分鐘，再按「開始新計時」。切換用途會自動帶入小組討論 6 分鐘／提交答案 1 分鐘，之後仍可手動調整；切換用途本身不會開始或修改正在進行的倒數。一次課堂只有一個倒數，開始新計時會取代該課堂舊倒數。暫停、繼續、±1 分鐘、結束並隱藏都同步到該課堂已加入的學生頁。

學生頁頂端顯示固定計時列；最後一分鐘以文字和顏色提示，歸零顯示時間到，不會自動鎖定或提交。組間討論沒有學生倒數選項。用途標籤不會改變 Stage 的作答權限。

關閉 Stage 會暫停其倒數，重新開放後需教師按「繼續」。鎖定／公布會結束顯示；課堂重置會清除正在顯示的計時。正式／TEST 分開儲存。教師開始計時前需開放未鎖定的 Stage。

## 安裝

1. 在既有 TBL Supabase 專案 SQL Editor 執行 `sql/session-timer.sql` 全文。這是交易式、可重複執行的新增遷移，不修改原有答案、分數、代表或 Stage 資料，也不取代既有 RPC。
2. 執行 `tests/session-timer-live.sql` 全文。它限定 TEST ID 與名稱；若沒有代表，僅在回復交易中暫借既有匿名帳號綁定 TEST。測試所有修改回復後，比對所有 `tbl_*` 資料指紋，最後顯示 PASS。若缺少可用匿名帳號，會中止，不改正式課堂。
3. 部署本版本 HTML／JS／CSS，重新整理教師、學生頁。

不必開啟 Supabase Realtime publication。沿用每 4 秒課堂更新取得伺服器截止時間及伺服器時間，瀏覽器使用 monotonic elapsed time 更新畫面；教師操作約在下次同步出現，非毫秒級同步。超過 15 秒未成功同步會顯示同步中，請以教師指示為準。瀏覽器回到前景會重新同步。

## 本機驗證

`node tests/session-timer.cjs`（需可解析 `@electric-sql/pglite`，或以 `PGLITE_PATH` 指向它）。涵蓋遷移重跑、權限、場次隔離、版本衝突、暫停繼續、時間調整、關閉鎖定重置，以及前端時鐘與過期回應隔離。

教師也可按「開啟同步投影」，在原 classroom-timer 大字畫面讀取同一課堂倒數。投影固定在開啟時的課堂，需同瀏覽器教師登入；切換課堂時請重新開啟投影。投影頁只讀，不提供時間操作。原獨立計時仍可使用；本次整合不需新 SQL 遷移。

真實手機背景休眠、不同網路延遲和全班多裝置負載仍需現場觀察。
