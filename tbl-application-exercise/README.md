# 2026 ID Block TBL Application Exercise — 單機教師版

## 開始使用
雙擊 `index.html`，以 Chrome、Safari 或 Edge 開啟即可，無須安裝或連接網路。桌面、平板均可使用。

## 課堂流程
1. 使用投影模式顯示 Stage 1；學生小組討論並在紙本或舉牌作答。
2. 教師退出投影模式，在右側為 13 組各選擇 A–E。
3. 全部 13 組有答案後，點選「鎖定本階段答案」，再點「公布答案與解析」。
4. 進入下一階段，重複以上流程。投影模式不顯示答案或分數表。
5. 四階段完成後，匯出 CSV 成績及 JSON 備份。

## 重要限制
這是**單機教師操作版**，不提供學生各自手機即時提交，也不會跨裝置同步。跨裝置即時作答需要後端、身分驗證及資料庫；不能只將這個 HTML 上傳 GitHub Pages 就得到這些功能。資料存於本機瀏覽器 localStorage；更換瀏覽器、清除網站資料或使用無痕模式可能遺失。建議每堂課匯出 JSON 備份。

本版將完整答案與教師分數包含在原始碼內，以利離線計分；學生如果能取得 HTML 原始檔，仍可查看答案。請只由教師開啟、以畫面投影，不要把 HTML 檔分享給學生。若需要學生各自登入並防止提前看到答案，請使用有後端的正式版本。
